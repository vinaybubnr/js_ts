# JS/TS Basics - Playwright2X

A JavaScript learning project covering core language fundamentals.

## Topics Covered

- **Variables** – `var`, `let`, `const`
- **Identifiers** – camelCase, PascalCase, snake_case, UPPER_CASE, `$` prefix, `_` prefix
- **Literals** – string, number, boolean values
- **Operators** – arithmetic and string concatenation
- **Comments** – single-line (`//`) and multi-line (`/* */`)

## Files

| File | Description |
|------|-------------|
| `JSBasics_spec.js` | JavaScript basics: variables, identifiers, operators |
| `Day01/` | Day 1 exercises folder |

## How to Run

```bash
node JSBasics_spec.js
```

## Prerequisites

- [Node.js](https://nodejs.org/) installed
